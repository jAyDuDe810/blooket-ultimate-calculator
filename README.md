# Blooket Pack Simulator Pro

A polished Blooket calculator and simulator built for quick strategy testing, probability analysis, and pack optimization.

## Features
- Target pull-rate analysis
- Starting token and pack cost modeling
- Resell / recycling logic
- Analytical success probability
- Monte Carlo simulation engine
- Expected value calculations
- Break-even and probability ladder outputs
- Modern responsive UI

## Open it locally
1. Download or clone the repo.
2. Open `index.html` in a browser.
3. Enter your inputs and click `Run engine`.

## File structure
- `index.html` — app shell and dashboard layout
- `styles.css` — modern dark UI styling
- `app.js` — probability engine and simulation logic

## Notes
This project is designed as a single-page browser tool, so no build step is required.
